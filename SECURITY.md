# Security policy

## Supported versions

There is no release yet. Once versions exist, the latest minor release receives security fixes.

## Reporting a vulnerability

Use GitHub private vulnerability reporting on this repository. Do not open a public issue for anything that could let an agent execute unintended SQL, read data outside a configured limit, or escape the metadata directory.

Include the dialect, the command called, the inputs, and the statement or behavior observed.

## Response

You will receive an acknowledgement within seven days and a fix or a written assessment within thirty. Reports are credited in the changelog unless you ask otherwise.
